# blog_code_examples — agent instructions

This is a software-delivery project at `personal/blog_code_examples`. Tasks are tracked in GitHub issues (`task-store.sh` in coding_agents).
The session journal is `docs/record/journal.md`. `CLAUDE.md` is a symlink to this
file, so both harnesses read the same instructions.

## How to write

- Plain English, ordinary words. Name things by what they are.
- Short sentences, under 25 words, one idea each.
- No AI attribution anywhere: not on commits, pull requests, issues or docs.
